DocConverter

Chuyển PDF, Word, Excel, PowerPoint, HTML, EPUB, ZIP, ảnh… sang Markdown / Word / HTML / TXT / JSON / Excel. PDF scan hoặc ảnh chụp công văn sẽ tự OCR (tiếng Việt). Xử lý ngay trong trình duyệt.

pdf · docx · xlsx/xls/csv · pptx · html · epub · zip · json/xml/ipynb · txt/md · jpg/png/webp…
Có thể chọn nhiều file / nhiều ảnh cùng lúc.
